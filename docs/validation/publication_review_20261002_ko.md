# SurvStudio 코드와 논문 전략 검토

SurvStudio는 생존분석의 기본 수치 계산과 분석 흐름을 검증할 수 있는 연구 도구로 발전할 가능성이 있다. 현재 가장 설득력 있는 기여는 새로운 예측 알고리즘의 우월성이 아니라, 마커 선택과 모델 비교 과정의 편향을 드러내고 고정 모델의 외부 검증으로 연결하는 작업 흐름이다. 이번 검토에서는 실제 결함을 수정하고, 주장 범위를 줄여야 하는 통계적 한계와 논문을 위해 추가할 증거를 구분했다. 현 상태를 제출 가능한 최종 연구 패키지로 판정하지 않는다.

검토 기준은 GitHub 원본 `5919c1d5223c8c4b86fd4849f3d8b7dd36ad86e6`, 버전 0.2.0이다. 수정은 `audit/20261002-publication-readiness` 브랜치에 보존했다. 실행은 Tailscale 서버의 영구 프로젝트 디렉토리에서 수행했다. 서버 선택 기록, 실행 로그, 환경 목록, 화면 캡처와 파일 해시는 별도 검증 자료에 보존했다.

## 검토 범위와 판단 기준

전체 소스 모듈과 테스트 구성을 조사하고, 데이터 업로드와 정렬, KM와 Cox 계산, 마커 선별과 순열 검정, 재표집, 범주 인코딩과 결측 대치, ML과 DL의 평가 분할, 조기 종료, 성능 지표, 그림과 보고서, 고정 모델 외부 검증, 연구 설계 점검, 웹 인터페이스 및 배포 경로를 검토했다. 전체 회귀 테스트, 실제 브라우저 테스트, 독립적인 R 수치 비교와 새 경계 사례·시뮬레이션을 실행했다.

전체 테스트의 통과는 모든 통계적 가정이나 모든 입력에서의 정확성을 증명하지 않는다. 이번 검토는 실제 실행과 핵심 위험 경로에 근거한 코드·주장 감사이며, 모든 줄에 대한 형식 검증이나 모든 지원 운영체제·GPU에 대한 재검증을 의미하지 않는다. 현재 실행 검증은 Linux x86_64, Python 3.12, CPU 환경이다. 실제 환자의 임상적 유용성이나 기존 외부 코호트 결과를 새로 검증한 것은 아니다.

## 순열 검정의 오탐률 실험

생존시간은 임상변수 `Z`에만 의존하는 Cox PH 모형에서 생성했고, 검열은 독립적으로 생성했다. 각 데이터는 180명과 마커 30개를 가진다. 마커는 결과에 직접 영향을 주지 않지만 `Z`와의 관계가 달라진다. added-value lens에서 마커 하나라도 step-down FWER p ≤ 0.05이면 오류 발생으로 기록했다. 시드는 `20261002`, 반복마다 별도 난수 흐름을 사용했다. 강한 FWER와 검정력, robust tier의 오류율을 동시에 시험한 것은 아니다. `n_resamples=0`이므로 여기의 FWER는 added-value 순열 p값의 family rejection이며 최종 robust 판정률이 아니다.

| 마커 생성 관계 | 1,000회 중 오류 | FWER | 95% Monte Carlo Wilson 구간 |
| --- | --- | --- | --- |
| `X = noise` | 49 | 4.9% | 3.7–6.4% |
| `X = 0.8Z + noise` | 45 | 4.5% | 3.4–6.0% |
| `X = 0.8Z + exp(0.8Z) noise` | 51 | 5.1% | 3.9–6.6% |
| `X = Z² + noise` | 70 | 7.0% | 5.6–8.8% |

마지막 조건에서는 5%가 이 구간 아래에 있다. 따라서 현재 구현에 대한 보편적인 5% FWER 문구는 지지되지 않는다. 첫 세 조건의 구간이 5%를 포함한다는 사실도 오류율이 정확히 5%라는 증명은 아니다. 네 조건은 전체 null이고 마커 간 잔차 상관, 임상변수 수 증가, 임상모형 오지정, 의존 검열, 부분 null은 다루지 않았다. 여기서의 구간은 반복 실험의 불확실성으로, 환자 성능 지표의 신뢰구간이 아니다.

Smith 방식의 근거로 쓰인 [Winkler et al. 2014](https://pmc.ncbi.nlm.nih.gov/articles/PMC4010955/)는 일반 선형모형의 순열 추론을 다룬다. 그 논문을 인용하는 것만으로 Cox score에 적용한 현재 절차의 모든 조건부 null에 대한 유효성이 확보되지는 않는다. 권장 후속 연구는 조건부 마커 모형의 비선형성·분산을 다루는 대안과 현재 방식을 독립적으로 비교하는 것이다. 교차적합 조건부 randomization, 더 유연한 nuisance adjustment, Cox 기반 재표집은 후보이며 검증된 해결책으로 선언하지 않는다.

## 결과와 해석에서 지킬 경계

**기본 생존분석.** KM와 Cox의 핵심 계산은 R과 잘 맞았다. 시간 단위, 사건 코딩, 대상 환자와 reference level을 고정해 보고해야 한다. Cox HR은 인과 효과가 아니며, Schoenfeld 진단은 모든 모형 오지정을 검출하지 않는다. competing risk와 left truncation은 현재 분석의 지원 범위 밖이다.

**마커 분석.** marginal association, 임상변수 보정 association, 추가 예측 가치는 서로 다른 질문이다. score p값과 내부 선택 안정성으로 임상적 유용성이나 새 환자에서의 개선을 선언할 수 없다. 보정 p값도 outcome이나 후보 목록을 반복해서 본 뒤 바꾼 전체 연구자의 선택 과정을 자동으로 교정하지 않는다. robust tier는 사전에 정한 내부 근거 등급이다.

**모델 비교.** 모델 간 동일 평가 환자와 분할 fingerprint, 평가 행 정렬, train-only 전처리와 조기 종료 monitor 분리를 점검하는 장치가 강점이다. 그러나 여러 모델 중 1위를 골라 같은 평가셋 성능을 최종 결과로 쓰면 선택 편향이 생긴다. paired bootstrap은 같은 고정 모델들을 평가 환자에서 비교하는 불확실성이고, 학습 데이터 변동·튜닝·우승 모델 선택을 전부 포함하지 않는다. fold percentile 범위는 명시된 대로 정식 95% CI가 아니다.

**중복 환자.** 표현 프로파일 중복 탐지는 위험 신호를 주지만 모든 동일 환자를 찾는 인증 절차가 아니다. 동일 환자나 병원·센터가 여러 행으로 존재하면 해당 단위로 분할해야 한다. 현재 행 기반 분할을 환자 그룹 기반 nested CV로 간주하지 않는다. 서로 다른 공개 코호트 사이에서도 중복을 확인해야 한다.

**외부 검증.** 고정 marker recipe의 coefficient, encoder와 baseline을 적용하는 경로는 실제 외부 검증의 기반이다. 반면 ML/DL 모델을 외부 코호트에서 다시 학습하는 것은 재개발이다. `within_cohort` rescaling은 외부 결과값을 사용하지 않지만 외부 feature 분포를 사용하는 플랫폼 적응이며, 모델을 전혀 변경하지 않은 측정 환경의 검증과 따로 보고한다. 절대 위험 calibration을 그대로 신뢰할 수 없다.

**기존 성능 주장.** pooled C 0.665와 임상모델 C 0.660의 차이 0.005만으로 추가 가치가 있다고 결론내릴 수 없다. 코호트를 단순 합쳐 계산한 C는 코호트 간 baseline 차이와 비교쌍의 영향을 받을 수 있다. 코호트별 paired ΔC와 CI, calibration, 지표 horizon, 검열 지원 범위 및 이질성을 먼저 보고한다. 기존 값이 사실과 다르다고 판정한 것은 아니며 현재 저장소에서 독립적으로 재현하지 못했다.

## 선행 도구와 차별화

2026년 10월 2일 확인한 가까운 선행 연구와 비교했다. 완전한 체계적 문헌고찰은 아니므로 “최초”나 기존 모든 도구에 대한 우위를 선언하지 않는다.

판단상 가장 강한 논문 주제는 **임상 연구자가 마커·모델 선택의 편향을 확인하고, 고정 모델의 독립 검증과 보고까지 수행하도록 돕는 로컬 생존분석 워크벤치**이다. 이를 주장하려면 실제로 잘못된 결론·분할·반복 선택을 줄이는지 검증해야 한다. “편향을 방지한다”는 현재의 확정 결과가 아니라 검증할 연구 가설이다. 알고리즘 논문보다 재현성·연구 작업 흐름 중심의 소프트웨어 논문이 현실적인 경로라는 것은 이번 검토자의 전략적 판단이다.

## 논문 가능성을 높이는 실행 순서

### 첫 단계 현재 결과를 검증 가능한 패키지로 복원

기존 외부 코호트 사례의 accession, 다운로드 경로와 날짜, assay와 gene mapping, 환자 ID, 중복 제거, 사건 정의·단위, 분석별 n과 사건 수, 결측 처리, exact recipe, 모든 선택과 분할을 기록한다. 원자료의 공유 조건에 맞게 데이터를 제공하거나 다운로드·변환 스크립트를 제공한다. frozen prediction과 원자료 해시를 연결한다. 독립 환경에서 표·그림을 다시 만들 수 있어야 한다.

현재 numerical agreement와 테스트 결과는 제출 근거의 일부가 될 수 있다. 순열 검정과 study-design map의 개발 pilot은 더 넓은 타당성 주장의 근거로 바로 승격하지 않는다. design map은 집계표를 사용하고 입력이 grid 밖일 때 가장자리 값을 쓰므로 정밀한 개인 연구의 편향 추정치가 아니라 예시적 경고로 다룬다. 원 생성기와 반복별 출력이 없으면 검증된 보편적 정량 예측 도구라는 표현을 피한다.

### 두 번째 단계 주장에 맞춘 확장 실험

| 연구 질문 | 사전 고정할 비교와 설계 | 주 지표 및 성공 판정 |
| --- | --- | --- |
| 오류 통제의 조건 | 현재 순열 방식과 사전 정한 대안을 전체 null·부분 null, 비선형 nuisance, 마커 상관, 독립·의존 검열에서 비교한다. threshold 선택용 실험과 평가용 seed를 분리한다. | FWER/FDR/power 및 Monte Carlo CI. 예를 들어 FWER를 5% ±1%p 정밀도로 추정하려면 조건별 약 1,825회가 필요하므로 2,000회 이상을 계획하고 최종 반복 수를 사전 고정한다. |
| apparent 및 부분표본 보정의 편향 | 동일 데이터와 후보 목록에서 apparent, gap-adjusted, 전체 선택을 포함한 bootstrap, nested CV, 고정 외부 검증을 비교한다. | 외부 C 대비 bias, RMSE, CI coverage, selection frequency. 대안을 검증하기 전 더 좋은 보정이라고 선언하지 않는다. |
| 임상변수 이상의 추가 가치 | 임상모델, 마커만, 임상+마커를 개발 단계에서 고정한다. 외부 코호트·센터·시간 분할은 선택에 사용하지 않는다. | paired ΔC, calibration slope와 O/E, 사전 정한 시점의 Brier/IBS. cohort별 결과와 이질성, 실패와 결측도 보고한다. |
| ML/DL 비교의 신뢰성 | train-only preprocessing, patient/center 단위 nested split, 동일 outer folds와 튜닝 예산을 사용한다. 작은 표본에서 DL 우위도 전제하지 않는다. | 여러 공개 코호트에서의 discrimination·calibration·실행시간·메모리, 실패율. 최종 성능은 sealed test나 외부 고정 모델로 평가한다. |
| 작업 흐름이 오류를 줄이는지 | 개발자 제외 사용자가 동일 공개 데이터에서 도구와 기존 작업 방식으로 사전 정한 분석을 수행한다. 순서와 데이터 버전을 균형 배정한다. | 잘못된 사건 코딩, 부적절한 재학습, best-of-many 결론 등의 오류율, 정답 수행률, 시간, SUS. 단순 만족도가 정확성을 대신하지 않는다. |

외부 검증의 표본 크기는 막연한 “100 events면 충분” 규칙보다 ΔC·calibration의 목표 정밀도와 사건 비율에 따라 산정한다. 8–12명 사용자 연구는 기존 protocol의 형성적 연구로 유용하지만, 도구 간 정량 우월성 주장은 별도 표본 크기 설계가 필요하다. 모집 전에 기존 IRB 판단·동의 절차를 따른다.

### 세 번째 단계 논문의 구조와 그림

가제는 “SurvStudio: a local workbench for auditable prognostic marker evaluation and survival model comparison”이다. 제목과 Abstract에서 새 알고리즘·예측 성능 우월성을 전제하지 않는다. Introduction은 도구 부족보다 분석 선택 편향과 검증·보고의 단절을 문제로 제시한다. Methods에는 전처리 학습 위치, 순열의 가정, 평가 분할, 잠근 모델, 반복 선택과 실패의 처리를 명확히 쓴다.

권장 그림은 다음과 같다.

1. 분석부터 고정 외부 검증·보고까지의 작업 흐름과 데이터가 사용되는 위치.
2. R 수치 비교와 경계 입력 검증. 재현 source와 표를 함께 제공.
3. FWER·power calibration의 조건별 결과. 현재 비선형 실패 조건도 포함.
4. 구성 요소 제거 실험: 전처리 분리, multiplicity, 안정성, 고정 검증이 각각 결과를 어떻게 바꾸는지.
5. 외부 코호트별 clinical versus clinical+marker 성능·calibration. 유리한 코호트만 선택하지 않음.
6. 실제 사용자 정답률·시간·오류 유형. 수행한 사용자 연구가 있을 때만 포함.

보조표는 데이터·환자 흐름, 모델·튜닝 예산, 정확한 software 환경, 전체 결과 및 실패, REMARK와 TRIPOD+AI 항목별 증거 위치를 담는다. 자동으로 채운 checklist는 연구가 기준을 충족했다는 인증이 아니다. [TRIPOD+AI 2024](https://www.bmj.com/content/385/bmj-2023-078378)의 보고 항목에 맞춰 실제 수행한 내용과 미수행 내용을 구분한다.

투고 전략상, 기술적 재현성과 사용자 검증을 갖춘 소프트웨어·의생명정보학 도구 논문을 첫 목표로 삼는 것이 합리적이다. 더 높은 영향력의 생물의학적 예측 연구를 목표로 한다면 추가 가치, 외부 calibration과 실제 적용의 독립 근거가 핵심이다. 특정 저널의 심사 가능성이나 게재 확률을 수치로 보장할 근거는 없다.

## 재실행 방법

Python 의존성은 `.[dev,e2e,validation]`, R은 `survival`과 `jsonlite`, 브라우저는 Playwright Chromium이 필요하다. 현재 감사에서는 CPU PyTorch와 BLAS·OMP 각 1 thread를 사용했다. 원 서버의 재현 환경 목록은 별도 보존했다. 결과를 기존 문서 위에 덮어쓰지 않도록 별도 출력 폴더를 지정한다.

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 python -m pytest -q --ignore=tests/test_browser_e2e.py
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 python -m pytest -q tests/test_browser_e2e.py
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 python validation/agreement/run_agreement.py --output audit_results/agreement --check
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 python validation/publication/run_marker_calibration.py --output audit_results/marker_calibration --replicates 1000 --permutations 499 --workers 4 --seed 20261002
```

이번 단계에서 코드 결함과 과도한 문구를 수정했지만, 조건부 순열 검정의 일반 유효성, 기존 외부 사례의 재현성, 실제 사용자의 오류 감소와 임상적 추가 가치는 아직 남은 연구 과제다. 이 경계를 공개하고 필요한 증거를 순서대로 확보하는 것이 논문의 신뢰성과 가능성을 높인다.
