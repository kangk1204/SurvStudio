# Complete guarded-inference evidence

This package contains synthetic fixtures and aggregate outcomes only. Neither new patient rows nor manuscripts are included.

- Frozen confirmation: 85,500 datasets, 256,500 paired method records, 39 cells, 2,184 immutable ownership ledgers. Both inference profiles failed the fixed engineering criteria and remain exploratory.
- Numerical reference: 14 spline/diagnostic and 84 workflow quantities; six discrete quantities require exact equality, solver quantities use maximum absolute error 1e-6.
- Existing external reanalyses: six development analyses, both marker scalings, 852 independent R quantities. Case V RFS and DMFS are separate. All conditional inference is withheld; estimable fixed predictions remain exploratory.
- Base R recomputes 2,826 operating-characteristic quantities from the compressed per-replicate outcomes. One original calculation failure remains in the denominators and failure bounds.
- Six standalone figures have PNG, PDF, SVG, source tables and structural manifests. Figure 1 is a schematic; Figures 2–3 and S1 show the frozen research prototype before the later product qualification mask. Structural validation does not certify scientific claims.

`aggregate-manifest.json` hashes fixed inputs and outputs, excluding derived aggregate-audit files to prevent a hash cycle. `aggregate-audit.json` records the exact manifest hash and audit source hashes. The original confirmation summary is retained byte-for-byte; completion is determined by its complete and missing-index fields.

See ../../../README.md and ../../../../docs/guarded_inference_validation.md for reproduction and interpretation. Preserve this study if any method is revised; use a new method version and seeds for a new confirmation study.
