# Final publication comparison

This comparison supplements the preserved v1, v2 and sealed v3 studies. It does
not change their numerical sources, thresholds, support sets or fixed owners.
Numerical agreement and workflow observations are distinct from statistical
qualification, clinical utility and human usability.

Run `comparison.py fixtures --output NEW_DIR` before any analysis. Its immutable
manifest freezes the existing eight-task inputs and five additional paired
synthetic challenges, their seeds, expected invariants and source hashes.
`comparison.py surfaces` evaluates state propagation using 999 marker
permutations, the unchanged v2 policy and the product export/recipe functions.
`comparison.py libraries` executes lifelines and the pinned mlsurv workflow,
retaining warnings, reports, model artifacts, fixed external predictions and
explicit task comparability. Added scripts are labelled as scripts, never as
native library features. A feature absent from documentation is not declared
unsupported.

KM Plotter requires operator permission for non-human execution under its terms.
Without permission, all eight tasks are access-limited and execution-unverified.
surviveR is executed by the agent after ordinary user authentication, if needed.
Account creation and messages to operators are not part of unattended execution.
Synthetic inputs only may be uploaded to these services.

Benchmark modes that remove warnings or withholding are analytical ablations;
they are not alternative product defaults or estimates of human error rates.
An altered external outcome must not change a frozen linear predictor. A changed
external covariate is expected to change prediction, while training parameters
and development withholding remain fixed.

Manuscripts and actual-case rows/recipes stay outside public Git. Public outputs
are scripts, synthetic fixtures, aggregate tables, hashes and reproduction records.

## Executed evidence on 9 October 2026

The current aggregate bundle is `results/20261009-r2`; the earlier bundle is
retained as an assembly checkpoint, not a second experiment. Six figures and
their exact source tables and manifests are in `figures-20261009`.

- Preserved v2: 85,500 datasets, 256,500 method records; finite main linear support.
- Sealed v3 main: 120,000 datasets, 600,000 method records; necessary adoption
  criterion failed. Heteroskedasticity withholding decreased by 33.70 and 48.98
  percentage points, exceeding the five-point margin. v3 stays experimental.
- Original v3 extension: 11,208 readable paired records, one unreadable record,
  791 absent results among 12,000 planned indices. Four started attempts remain
  unresolved. The whole unreadable record remains unusable, without partial
  salvage. This descriptive audit is not independently R-verified qualification.
- Large-marker and new stress studies were undispatched at this audit snapshot.
  Their fixed planned counts are included, with unknown result ranges.
- Nine state checks, 84 eight-task R checks, 15 lifelines checks, 292 actual public
  case R checks, 6,325 main aggregate R checks and eight common task/engine
  benchmark comparisons passed their respective declared checks.
- A brand-new second-server environment reproduced all nine synthetic artifacts
  exactly. This demonstrates implementation reproducibility within this fixture.
- Native mlsurv diagnostics, reports, save/load and external validation executed.
  These are prior capabilities. Different diagnostic targets are not failures.
- The public Rotterdam/GBSG benchmark produced a small positive paired C gain;
  its development conditional inference remained withheld in all four analyses.
- surviveR authentication and KM Plotter operator permission are pending. Neither
  web tool is labelled unsupported on the basis of nonexecution.

The five-pair surface analysis uses 999 marker permutations. The separate
eight-task reference harness uses 99 permutations and four resamples as an
implementation check; it is not a new 999-permutation confirmation study.
Outcome-role checks reject declared column overlap. They do not establish
detection of every proxy or outcome-derived feature.

## Reproduction

Use the preserved calculation source and the recorded Python/R environments.
mlsurv is pinned to 0.2.0 and lifelines to 0.30.0. The test environment additionally
needs the declared dev and browser extras. A dependency lock is evidence of the
specific environment, not a promise about every later dependency version.

```sh
python validation/publication_final/verify_aggregates.py \
  --inputs validation/publication_final/results/20261009-r2
python validation/publication_final/figures.py \
  --inputs validation/publication_final/results/20261009-r2 \
  --output /absolute/path/to/a/new/figure-directory
python validation/publication_final/comparison.py --help
python validation/publication_final/tool_probes.py --help
python validation/publication_final/native_followups.py --help
python validation/publication_final/fresh_environment.py --help
python validation/publication_final/benchmark.py --help
```

All execution outputs require a new persistent directory. Do not overwrite an
original study ledger or rerun completed, failed or uncertain attempts to replace
them. `audit_ledgers.py` is read-only. `refresh_existing_diagnostics.py` reevaluates
the complete original development marker family with 9,999 draws, while asserting
unchanged clinical/model/marker components and external metrics. Its patient-level
inputs and actual recipes must remain private. Prior external v2 diagnostics are
retained; a development state refresh does not newly certify external v3 checks.

Benchmark timing is for matched small KM/Cox calculations on one shared server,
after three warmups and ten measured runs. Whole-process RSS includes imports.
mlsurv timing measures the Cox model core, not its full CV/reporting workflow.
No general speed or human-usability claim follows from these observations.

The paper package is a review draft. Author declarations, web access gaps,
incomplete fixed confirmation cells and latest-source CI are tracked separately.
No submission, formal release or public archival publication is authorized here.
